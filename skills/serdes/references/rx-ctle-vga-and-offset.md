# SerDes RX Front-End: CTLE, VGA & Offset Calibration

## 1. Source-Degenerated RC CTLE Transfer Function

The canonical CMOS Continuous-Time Linear Equalizer (CTLE) is a differential pair with load resistors $R_D$ (and parasitic load capacitance $C_P$) degenerated by parallel $R_S \parallel C_S$ between the two source nodes:

$$H_{\text{CTLE}}(s) = \frac{g_m R_D}{1 + \dfrac{g_m R_S}{2}}\,\cdot\,\frac{1 + s/\omega_z}{\left(1 + s/\omega_{p1}\right)\left(1 + s/\omega_{p2}\right)}$$

where:
- **Zero frequency:** $\omega_z = \dfrac{1}{R_S C_S}$
- **Dominant peaking pole:** $\omega_{p1} = \dfrac{1 + g_m R_S / 2}{R_S C_S} = \left(1 + \dfrac{g_m R_S}{2}\right)\omega_z$
- **Output bandwidth pole:** $\omega_{p2} = \dfrac{1}{R_D C_P}$
- **DC gain:** $A_{\text{DC}} = \dfrac{g_m R_D}{1 + g_m R_S / 2}$
- **Maximum high-frequency peaking ratio (when $\omega_{p2} \gg \omega_{p1}$):**
  $$\text{Peaking}_{\text{dB}} \approx 20\log_{10}\!\left(1 + \frac{g_m R_S}{2}\right)$$

### Sizing Guidelines
1. **Place $\omega_{p1}$ near the Nyquist frequency $f_{\text{Nyq}} = f_b / 2$** (e.g., `5–6 GHz` for `10 Gb/s` NRZ, `12–15 GHz` for `28 Gb/s`), and keep $\omega_{p2} \ge 1.5\text{–}2.0\,\omega_{p1}$ (use shunt inductive peaking $L_D$ in series with $R_D$ if $C_P$ caps $\omega_{p2}$!).
2. **Choose boost ratio $1 + g_m R_S / 2$** to match the channel's DC-to-Nyquist loss slope (`6–12 dB` per single stage; cascade 2–3 moderate-peaking stages for `> 15 dB` equalization rather than over-degenerating one stage, which kills DC gain and ruins linearity!).
3. **Avoid excessive peaking:** Over-equalizing creates negative post-cursor ringing ($h_1 < 0$) and amplifies high-frequency input noise and crosstalk proportionally to $\int |H_{\text{CTLE}}(f)|^2 df$!
4. **Programmability:** Implement $R_S$ and $C_S$ as binary/thermometer switchable banks (watch switch $R_{\text{on}}$ and parasitic drain cap!) so the CTLE adapts across short (`< 5 dB`) and long (`> 20 dB`) channels.

## 2. Variable-Gain Amplifier (VGA) & Cascade Budgeting

A broadband **VGA** (flat frequency response, $f_{-3\text{dB}} \ge 0.7 f_b$) follows the CTLE to normalize the differential eye swing at the DFE summer / slicer input (typically `300–600 mVpp_diff`), maximizing signal margin over slicer offset and thermal noise without saturating the front end.

- **Linearity (`P1dB` / THD):** On short channels with large RX swing, the CTLE/VGA must back off gain cleanly so nonlinear compression does not distort ISI cursors (nonlinearity breaks linear CTLE/FFE/DFE superposition!).
- **Noise accumulation:** Verify total integrated differential output noise (`100 kHz..2 f_b`) in [`../assets/tb/ctle_vga/tb_ctle_ac_noise.scs`](../assets/tb/ctle_vga/tb_ctle_ac_noise.scs) and check the signal-to-noise ratio at the slicer:
  $$\text{SNR}_{\text{eye}} = \frac{V_{\text{eye,height}} / 2}{\sigma_{n,\text{out}}} \ge Q(\text{BER}) \quad \left(Q = 7.03 \text{ for } \text{BER} = 10^{-12}\right)$$

## 3. Front-End Offset Calibration Loop

Because a cascaded 3-stage CTLE + VGA has `10–20 dB` of DC gain, even a `5 mV` input mismatch produces `20–50 mV` of output offset — eating directly into vertical eye height and causing duty-cycle distortion!

- **Foreground / Background Calibration Topology:**
  1. Short the differential front-end inputs (`INP = INN = Vcm`) during startup calibration.
  2. Observe the sign of `OUTP - OUTN` with the data slicer (or a dedicated calibration comparator) at a slow divided clock (`f_cal << f_b`).
  3. Apply a **majority-vote digital filter** (`vote_th = 4–8` samples) inside the calibration FSM ([`../assets/va/va_offset_cal_fsm.va`](../assets/va/va_offset_cal_fsm.va)) so thermal noise near zero offset does not trigger premature termination.
  4. Drive a signed **current-steering offset IDAC** (`±15` to `±31` LSBs, covering $\ge \pm 4\sigma$ Monte Carlo offset with `v_lsb ~ 1–2 mV`) summing into the CTLE/VGA load nodes until the sliced polarity flips cleanly across zero (`DONE = 1`).
- Verify end-to-end convergence and residual offset (`< 1 LSB`) using [`../assets/tb/ctle_vga/tb_vga_offset_cal.scs`](../assets/tb/ctle_vga/tb_vga_offset_cal.scs).
